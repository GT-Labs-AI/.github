# 🔬 AI R&D

Commercial engineering is only one part of GT Labs.

We also investigate lower-level AI systems, with a particular focus on **efficient neural network inference, model compression, GPU computing, and AI memory architectures**.

---

## 🚀 OTF-LLM Engine

**[otf-llm-engine](https://github.com/GT-Labs-AI/otf-llm-engine)**

An experimental LLM inference and weight-optimization engine exploring on-the-fly weight reconstruction and low-bit inference.

### Research areas

* INT4 quantization
* Outlier-aware weight handling
* Custom GPU kernels
* OpenAI Triton
* VRAM optimization
* On-the-fly weight synthesis
* Inference performance

The project includes benchmark tooling for comparing optimized models against higher-precision baselines.

> **Research results are reported through reproducible benchmarks rather than theoretical claims.**

---

## 🧠 Graph Memory Research

**[gt-labs-graph-memory-research](https://github.com/GT-Labs-AI/gt-labs-graph-memory-research)**

An experimental research framework exploring graph-based memory architectures for AI agents.

### Research areas

* Structured long-term memory
* Temporal information
* Contradiction resolution
* Graph-based retrieval
* Subgraph RAG
* Memory relevance and decay

The goal is to investigate alternatives to purely context-window-based memory systems.

# 🧪 Engineering Philosophy

### AI-accelerated, engineering-driven

We use modern AI tools to accelerate development, research, debugging, and exploration.

**AI is a development multiplier — not a replacement for engineering.**

Our workflow focuses on:

* Understanding the actual problem before implementation
* Reusing proven technologies where possible
* Writing maintainable and testable code
* Measuring performance instead of guessing
* Using AI where it provides a genuine advantage
* Validating generated solutions through testing and review
